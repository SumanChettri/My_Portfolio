# 🚀 Suman Chettri - Developer Portfolio

A modern, responsive, and feature-rich portfolio website built with **React 19**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

## ✨ Features

- **Personal Branding**: Unified profile, skills, education, and contact form.
- **Dynamic GitHub Integration**: Automatically fetches public repositories and live projects via the GitHub REST API.
- **Interactive Backgrounds**: Particle effects powered by `tsparticles`.
- **Glassmorphism & Micro-animations**: Smooth Framer Motion animations and dynamic scroll parallax.
- **Dark Mode Support**: Persistent dark/light theme toggle.
- **Responsive Layout**: Tailored for all screen sizes from mobile to desktop.
- **SEO Optimized**: Standardized Open Graph, Twitter card, and meta tags for web discoverability.

## 🛠️ Tech Stack

- **Frontend Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [React Scroll Parallax](https://react-scroll-parallax.vercel.app/)
- **Particles**: `tsparticles` & `react-tsparticles`
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **Form Backend**: [FormSubmit](https://formsubmit.co/)

## 🚀 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SumanChettri/My_Portfolio.git
   cd My_Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
